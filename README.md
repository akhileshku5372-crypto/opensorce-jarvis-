# opensorce-jarvis-
An open-source, Free Full Duplex Voice Assistant for Windows. Features real-time voice with barge-in, 3D holographic neural brain HUD, local OS action bridge, persistent ChromaDB long-term memory, built-in Edge-TTS, KamiSensei RAG, and multimodal perception with YOLOv10 object tracking, face detection &amp; MediaPipe hand gesture controls.
